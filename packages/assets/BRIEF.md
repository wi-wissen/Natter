# Brief for asset agents

You produce one pack of game graphics (PNG, flat emoji style) for a browser Python teaching environment (students aged 12 to 18 use the images as sprites, e.g. `Actor("name")`, and swap frames to animate).

1. Read `CONVENTIONS.md` first, then `scripts/asset-gen/README.md`, `gen.py`, `keyslice.py`. Look at `scripts/asset-gen/style-emoji.png` (the style and the two main characters) and at the finished pack `packages/assets/characters` (look at a few files) so that your pack matches.
2. Work in your own folder `packages/assets/<pack>/`; scratch files in `/tmp/claude-0/-home-user/82af8643-7fd2-511f-b912-5aee8d74fb4e/scratchpad/assets-work/<pack>/`. Do not use git; do not touch other packs.
3. Method: for each sheet write a prompt that lists exactly N objects (or one animation of K frames) in a fixed grid and reading order, attach `style-emoji.png` as the reference (and a second reference image when you need a certain character), demand a flat pure magenta (#FF00FF) background, no shadows, no ground, no text. Run `gen()` (it calls OpenRouter with `curl`; credentials are injected, call it from `python3` with `sys.path` set to `scripts/asset-gen`), then `keyslice.cut_items` (different objects) or `keyslice.align`/`frames` (animations). If the count is wrong or objects touch, change the prompt (fewer objects per sheet, more spacing) and try again. LOOK at every result: build a contact sheet on a dark and a light background and view it; redo what is ugly, off-style, copyrighted-looking, or has fringes. Backgrounds (tag `background`) are generated without magenta and scaled to 800x480.
4. Write `packages/assets/<pack>/pack.json` (format png, German and English descriptions, tags) and keep your prompts and names in `packages/assets/<pack>/make.py`. Run `npx vitest run packages/assets` and fix what it reports. Names must be unique over all packs: `ls packages/assets/*/pack.json` and check.
5. Everything must be original: do not imitate an existing game, film or brand character or its distinctive silhouette (no plumber, no mushroom-walking enemies, no yellow circle with a mouth, no famous hedgehog, no familiar bird-and-pipes silhouette, no yellow electric mouse etc.).
6. Final report: pack name, number of files, the names grouped, what you were unsure about. Keep it short.
