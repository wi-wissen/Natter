The asset library of Natter: about 900 sprites in one flat, friendly style and 14 short sounds, free to use (CC0). A program only writes the name, nobody uploads files. Pick a game type, search, and click a name to copy it.

# an image as a figure that moves
ente = Actor("ente", (200, 150))

def draw():
    screen.blit("teich_hintergrund", (0, 0))
    ente.draw()

def on_mouse_down():
    sounds.platsch.play()

print(images.ente.get_width())   # the image itself
  • Actor("name") makes a figure, screen.blit("name", (x, y)) draws an image, images.name is the image itself, sounds.name.play() plays a sound.
  • Animations are numbered: heroine_run_1 to heroine_run_8. Switch actor.image to play them; the detail view shows the code.
  • Kara draws its world with the kara pack (kara, kara_tree …) and the turtle wears turtle; both work as normal images too.
  • An own file with the same name in the project folder images/ wins. More in the reference: asset library.
